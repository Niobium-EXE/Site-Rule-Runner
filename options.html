CSS Hide Rules

Hide elements on matching websites using a class name or any CSS selector. Rules can have optional titles to make them easy to recognize.

JavaScript Rules

Run custom JavaScript on matching page loads, or test edited code immediately on matching open tabs.

Import & Export

Back up all CSS and JavaScript rules, including their titles, or move them to another browser.

Export configuration

Downloads one JSON file containing every rule, title, and enabled state.

Import configuration

Importing replaces the rules currently stored in this extension. Older configs without titles still work.

Delete all rules

Clears all saved CSS and JavaScript rules from this browser.

Edit rule

For example: Hide sidebar ads, Blue chat messages, or Fix page controls.
Examples: example.com, example.com/account/*, https://example.com/*, *://*.example.com/*, <all_urls>
A simple class name is automatically converted to .class-name.
Live editingTest the code currently in the editor without saving or reloading the page.
